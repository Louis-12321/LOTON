# Contributing to LOTON

Thanks for your interest, here's how you can help:

## How to contribute
1. Fork this repository
2. Create a new branch: `git checkout -b my-feature`
3. Make your changes
4. Submit a Pull Request

## Ideas welcome
- New built-in apps
- Bug fixes
- UI improvements
- New CMD commands

## Rules
- Credit the original author (Louis)
- Keep the MIT License header in all .py files
- Don't break existing features (Unless you're experimenting or have a good reason to)
